# tokyo-night-moon.yazi

A revised Tokyo Night color scheme for Yazi, original theme is https://github.com/BennyOe/tokyo-night.yazi

This version improved the code preview colors and update the original `flavor.toml` to support new version of yazi.

## Installation

```shell
ya pkg add likelikeslike/tokyo-night-moon
```

Add

```toml
[flavor]
dark = "tokyo-night-moon"
```
